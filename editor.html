Conectar el editor

Para publicar cambios, el editor necesita una clave de acceso de GitHub con permiso sobre el sitio. Se pega una sola vez y queda guardada solo en este dispositivo.

¿Cómo se usa?
  1. Cambiá precios o estado directamente en la lista, o tocá Editar para cambiar todo (nombre, fotos, descripción).
  2. Los cambios se guardan solos como borrador en este dispositivo, pero todavía no se ven en la web.
  3. Cuando termines, tocá Publicar. En 1 o 2 minutos aparecen en miver.com.ar.
